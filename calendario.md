## Cómo se usa

- En `lugares.js`, cada lugar lleva `numero` (columna «Lugar») y `publicar` (columna «Fecha», en formato `2026-11-08`).
- Conviene dejar cada lugar subido a GitHub el jueves anterior y revisarlo con `?l=<id>&previa`.
- Si un enlace se abre antes de su fecha, la web avisa: «Nazaret se publica el domingo 1 de noviembre».
- Las fechas se pueden mover: es una propuesta.
